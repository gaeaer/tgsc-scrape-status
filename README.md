# TGSC scrape status

Public static mirror of the private [TGSC research scraper](https://github.com/gaeaer/tgsc-scraper) progress dashboard.

- Live site: https://gaeaer.github.io/tgsc-scrape-status/
- Source SPA: private repo `dashboard/`
- Data: rebuilt from the scrape artifact (progress, samples, suggested views, trimmed sql.js database)

This repository only hosts the built GitHub Pages site on branch `gh-pages`.
